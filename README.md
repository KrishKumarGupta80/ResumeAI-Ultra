# ResumeAI-Ultra 🚀

AI-powered Resume Analysis & Job Matching Platform.

## 📌 Overview

ResumeAI-Ultra is a Flask-based web application that helps users analyze resumes, evaluate ATS compatibility, identify skill gaps, and match resumes with suitable job opportunities.

## ✨ Features

- 📄 Resume analysis
- 🎯 ATS score evaluation
- 🔍 Skill gap detection
- 💼 Job/recruiter matching
- 📊 Resume insights

## 🛠️ Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
